# HUDPositioner
HUD Positioner is a mod for The Long Dark that allows extended customization of the in-game UI elements by changing where they are anchored on the screen and freely adjusting their position via Mod Settings.

Currently supports:
- Status Bar (Anchor + Offset)
- Sprint Meter + Adjacent Elements (Anchor + Offset)
- Safehouse Icon (Anchor + Offset)
- Affliction Pop-Ups (Offset)
- Location Visit/Discover Messages (Offset)
Note: keep in mind that the mod does not prevent overlap of UI elements, you can use offsets to prevent UI elements from overlapping if you want them to be anchored to the same part of the screen.
